# ProgOto — Haftalık Ders Programı

Tek dosyalık tarayıcı tabanlı okul ders programı uygulaması. Sunucu, kurulum veya internet bağlantısı gerektirmez.

## Kurulum

`index.html` dosyasını çift tıklayıp tarayıcıda açın. Tüm veriler `localStorage`'da saklanır.

## Özellikler

- Ders kataloğu, öğretmen tanımı, sınıf yönetimi
- Otomatik dağıtım motoru (öğretmen yükü + kısıtlar)
- Saat/gün kilitleme, sürükle-bırak, çakışma uyarısı
- Öğretmen filtresi, dashboard, JSON yedekleme
- Yazdırma, 3 sn yükleme animasyonu, modern indigo-teal arayüz
